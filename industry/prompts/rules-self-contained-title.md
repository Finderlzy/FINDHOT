
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：国家 / 政府 / 国际组织 / 人物。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是没信息量的 teaser（如 "Live updates"、"What we know"、"Day 100"、"突发"）时，结合【来源】和正文把主体和事件补进标题。例：原标题 "What we know so far" + 正文讲以色列空袭黎巴嫩南部 → "以色列空袭黎巴嫩南部：目前已知的情况"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体主体时，用上位词（如"西方国家""武装组织"）兜底，绝不凭"常识"编一个具体国家 / 组织 / 人物 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / Benchmark 这类解释、分析、教程或评测标题，中文标题必须保留这个类型；不能因为正文谈到一个已经发生的事件，就改写成“宣布 / 签署 / 发动 / 实施”。只有原标题明确报道了这个动作，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的国家、组织、人物名。
   例：原标题 "Why the EU's new sanctions on Russia may not bite" → "为什么欧盟对俄新制裁可能收效有限"，不能写成 "欧盟宣布对俄新制裁"。
   例：原标题 "How the ceasefire talks broke down" + 正文明确是加沙停火谈判 → "加沙停火谈判是如何破裂的"，不能只写成缺主体的 "停火谈判是如何破裂的"。
