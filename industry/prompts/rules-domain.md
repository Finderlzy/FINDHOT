
【国际新闻翻译规则 — 本平台内容是国际形势新闻，严格遵守】

1. 国家、地名、人名一律用中文通行译名（以新华社译名为准），不保留英文：
   - 国家与地区：United States = 美国，UK / Britain = 英国，Russia = 俄罗斯，Ukraine = 乌克兰，Iran = 伊朗，Israel = 以色列，North Korea / DPRK = 朝鲜，South Korea = 韩国，Gaza = 加沙，West Bank = 约旦河西岸
   - 首都常用作政府代称时，按语境译成政府或国家：Washington = 美国政府 / 华盛顿，Moscow = 俄方 / 莫斯科，Kremlin = 克里姆林宫，Beijing = 北京
   - 人名用通行中文译名（如 Zelensky = 泽连斯基，Putin = 普京，Netanyahu = 内塔尼亚胡）；拿不准通行译名的人名，首次出现写中文音译并在括号里保留英文原名，绝不编造身份或职务

2. 国际组织与机构用中文通行名称，常见缩写可在首次出现时括注：
   - 联合国（UN）/ 安理会 / 联合国大会 / 北约（NATO）/ 欧盟（EU）/ 欧盟委员会 / 七国集团（G7）/ 二十国集团（G20）/ 国际货币基金组织（IMF）/ 世界贸易组织（WTO）/ 欧佩克（OPEC）/ 国际原子能机构（IAEA）/ 国际刑事法院（ICC）/ 国际法院（ICJ）/ 东盟（ASEAN）/ 金砖国家（BRICS）
   - 政府部门：State Department = 美国国务院，Pentagon = 五角大楼，Foreign Ministry = 外交部，Defense Ministry = 国防部，Treasury = 财政部（美国）

3. 立场与措辞忠实原文，不加强、不减弱：
   - 保留原文的归属：said / claimed / alleged / according to 分别译为“称”“声称”“指控”“据”，不要把单方说法写成既定事实
   - 区分 ceasefire（停火）/ truce（休战）/ armistice（停战协定），sanction（制裁）/ tariff（关税）/ export control（出口管制），invasion / offensive / strike（入侵 / 攻势 / 打击）
   - 对争议地区、争议事件的命名，照原文的说法翻译，不替原文换成另一方的说法

4. 数字 / 日期 / 单位 / URL **一字不改**保留：
   - 伤亡、人数、金额、百分比、导弹与兵力数量保留原文的阿拉伯数字和单位；不要把 $10B 改写成“上百亿美元”这类模糊说法
   - 原文写的是估计值、上限或区间时，照写“约”“至少”“最多”，不要改成确数
   - URL 原样
